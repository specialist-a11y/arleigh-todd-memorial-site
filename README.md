# In loving memory of Arleigh Arthur Patrick Todd
**20 March 1961 — 25 August 2026**

Memorial page for the candlelight vigil. Guests scan a QR code, browse photos and videos, light a candle with their name, and leave a tribute. Visitors can also edit or remove their candle and tribute from their device.

## Files

- `index.html` is the whole page (mobile-optimized styles and script included)
- `media/` holds the 53 photos, 2 videos, and video posters, numbered in gallery order
- `config.js` holds the Supabase settings for the shared candle wall

## Shared Candle & Tribute Wall (Supabase Setup)

With `config.js` left blank, candles and tributes are saved only on the visitor's own device (`localStorage`).

To share candles and tributes with everyone, add your Supabase project URL and publishable key to `config.js`. Run the following SQL in your Supabase SQL Editor:

```sql
-- Create candles table with tribute column
create table public.candles (
  id bigint generated by default as identity primary key,
  name text not null,
  tribute text,
  created_at timestamptz default now() not null
);

-- Enable Row Level Security (RLS)
alter table public.candles enable row level security;

-- RLS Policies
create policy "Allow public read access" on public.candles for select to anon using (true);
create policy "Allow public insert access" on public.candles for insert to anon with check (char_length(name) >= 1 and char_length(name) <= 40);
create policy "Allow public update access" on public.candles for update to anon using (true);
create policy "Allow public delete access" on public.candles for delete to anon using (true);
```

## Hosting

Any static host works: GitHub Pages, Netlify, or a folder on your own server. The page must be served over HTTPS, and every file must keep the same relative paths.
